# Contributing

Use the file placement and metadata guidance in [README.md](README.md). Contributors submit pull requests to `develop`; release maintainers promote `develop` to `main` after review.

By opening a contribution pull request, you confirm that you have authority to submit the material, that you have identified third-party material and assets, and that you grant MythicTomes the hosting permission described in [LICENSE.md](LICENSE.md). You retain copyright in your original work.

Keep pull requests focused. Do not include internal instructions, machine-specific files, assistant configuration, credentials, or private source material.
